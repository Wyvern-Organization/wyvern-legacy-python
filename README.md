# wyvern-legacy-python

wyvern-legacy-python a legacy version of [Wyvern](https://wyvernhub.net) that was originally written in Python.

## Stack

This codebase uses the following stack: 
  - Python: FastAPI for serving and backend.
  - Plain HTML/CSS/JavaScript: (no required dependencies) used for frontend.

## Is this the same as [Wyvern](https://wyvernhub.net)? 
No. This is the legacy Python-based version of Wyvern.
